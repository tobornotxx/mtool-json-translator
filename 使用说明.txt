MTool 文本翻译器 v1.0

这个程序读取 MTool / MTools 提取的 JSON 文本映射，保持键名不变，将文本值译为简体中文，再生成可导入替换工具的新 JSON。
本项目是纯 Vibe Coding 的个人备份和代码存档项目，欢迎试用并反馈问题。

使用
1. 双击 MToolTranslator-v1.0.exe。
2. 选择输入 JSON，确认新的输出路径。
3. 填写 API Base、API Key 和 Model Name。
4. 可先检查术语建议，再点击开始翻译。
5. 完成后把新 JSON 加载到翻译替换工具，检查游戏内显示效果。

接口配置
支持 OpenAI 兼容的 Chat Completions 接口，可以使用其他服务商或本地模型网关。
API Base 留空时，使用灰色提示的 https://api.deepseek.com。
Model Name 留空时，使用灰色提示的 deepseek-flash。
API Key 必须自己填写，只在本次会话内存中使用，不保存。
程序不查找其他项目的配置，也不内置任何个人密钥、游戏路径或用户目录。

术语与进度
术语表只提供默认建议，允许 AI 说明当前词义和理由后保留其他译法。
控制符和变量数量等格式问题仍严格检查。
停止时点击停止并保存，等当前请求结束后再关闭；下次选择相同输入、输出和模型配置可以续译。
已完成翻译后，点击查看已保存的术语例外，可在日志中查看原文、AI 译文和 AI 理由，不调用 API。
这些记录和缓存保存在输出文件旁的同名 .work 文件夹，不需要上传到公开仓库。

原始文件不覆盖。AI 翻译、术语和理由可能有误，需要结合实际语境核对。
